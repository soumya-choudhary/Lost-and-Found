1. Global Helper Functions & Config
config/database.php Class: Database
loadEnv(string $path): void ENV
Parses key-value lines from the .env file into PHP environment variables (putenv & $_ENV).
Database::getConnection(): PDO SINGLETON
Singleton database connection. Creates and returns a single active PostgreSQL PDO instance with error mode ERRMODE_EXCEPTION and native prepares.
pgsql:host={$host};port={$port};dbname={$name};
config/app.php Global Helpers
url(string $path = ''): string URL
Generates an absolute URL by prefixing APP_URL (e.g. url('login.php') → http://localhost/Lost-and-Found/login.php).
redirect(string $path): void NAV
Safe HTTP redirection. Sends Location: ... header and immediately terminates script execution.
setFlash(string $type, string $message): void SESSION
Stores a one-time flash notification in session ($type: 'success', 'danger', 'warning', 'info').
getFlash(): ?array SESSION
Retrieves the current flash notice and immediately deletes it from $_SESSION['flash'] so it only displays once.
isLoggedIn(): bool AUTH
Checks if the current visitor is authenticated (returns true if !empty($_SESSION['user_id'])).
isAdmin(): bool ROLE
Checks if the currently logged-in user has administrator privileges ($_SESSION['user_role'] === 'admin').
currentUser(): ?array USER
Returns an associative array ['id', 'name', 'email', 'role'] of the logged-in user, or null if guest.
sanitize($val): string XSS PROTECTION
Wraps htmlspecialchars(trim((string)$val), ENT_QUOTES, 'UTF-8') to neutralize malicious script injection.
isItemOwner(array $item, ?array $user = null): bool OWNERSHIP
Returns true if user is the reporter of the item (matches item.user_id === user.id OR item.contact_email === user.email).
canManageItem(array $item, ?array $user = null): bool PERMISSIONS
Central authorization rule: returns true if user is either an Administrator OR the Original Reporter.
typeBadgeClass(string $type): string BADGE
Returns Bootstrap badge class: bg-danger for 'lost', bg-success for 'found'.
statusBadgeClass(string $status): string BADGE
PHP 8 match block returning custom CSS classes: badge-status-open, badge-status-claim-requested, or badge-status-resolved.
claimBadgeClass(string $status): string BADGE
Returns badge class for claim decisions: bg-success ('Approved'), bg-danger ('Rejected'), bg-warning ('Pending').
itemImageUrl($itemOrPath = null): string IMAGE
Resolves image URL. If uploaded photo path is missing, returns default fallback public/assets/img/placeholder.svg.

3. Database Repositories (PDO SQL Queries)

Fetches single user by email (case-insensitive search).
SELECT * FROM users WHERE LOWER(email) = LOWER(:email) LIMIT 1
emailExists(string $email): bool
Returns true if email already exists in users table.
findById(int $id): ?array
Fetches user profile by primary key id.
SELECT id, name, email, phone, role, created_at FROM users WHERE id = :id
create(string $name, string $email, string $password, ?string $phone = null): ?int
Hashes password with password_hash(..., PASSWORD_BCRYPT), inserts record with default role 'user', and returns the generated id.
INSERT INTO users (name, email, password_hash, phone, role) VALUES (...) RETURNING id
updateRole(int $userId, string $newRole): bool
Promotes or demotes user role between 'user' and 'admin'.
UPDATE users SET role = :role WHERE id = :id
getAll(int $limit = 100): array
Fetches all registered users ordered by creation date for the Admin Users console.
SELECT id, name, email, phone, role, created_at FROM users ORDER BY created_at DESC LIMIT :lim
app/repositories/ItemRepository.php Class: ItemRepository
getAllCategories(): array
Fetches all categories for dropdown selectors and filter lists.
SELECT * FROM categories ORDER BY name ASC
create(array $d): ?int
Inserts a new lost or found report into items and automatically logs a 'Created' event in activity_logs.
INSERT INTO items (item_type, title, category_id, location, event_date, description, image_url, status, user_id, contact_name, contact_email, contact_phone) VALUES (...) RETURNING id
syncClaimRequestedItems(): void
Auto-synchronization: Reverts any item marked 'Claim Requested' back to 'Open' if it no longer has any pending claims.
UPDATE items SET status = 'Open' WHERE status = 'Claim Requested' AND id NOT IN (SELECT DISTINCT item_id FROM claims WHERE status = 'Pending')
searchAndFilter(array $f = []): array
Builds dynamic SQL query with ILIKE keyword search (title, description, location), category filter, item type filter ('lost'/'found'), status filter, and custom sorting.
SELECT i.*, c.name AS category_name, c.icon AS category_icon, u.name AS reporter_name FROM items i JOIN categories c ... WHERE ...
findById(int $id): ?array
Finds a single item joined with category name/icon and reporter name/email.
SELECT i.*, c.name, u.name AS reporter_name FROM items i JOIN categories c ... WHERE i.id = :id
updateStatus(int $id, string $status, string $remarks = ''): bool
Updates status ('Open', 'Claim Requested', 'Resolved') and automatically records a new audit entry in activity_logs.
UPDATE items SET status = :status, updated_at = CURRENT_TIMESTAMP WHERE id = :id
getByUserId(int $uid): array
Fetches all items reported by a specific user with a subquery counting incoming claims.
SELECT i.*, c.name, (SELECT COUNT(*) FROM claims WHERE item_id = i.id) AS total_claims FROM items i ... WHERE i.user_id = :uid
getStats(): array
Aggregates portal analytics counters using PostgreSQL FILTER (WHERE ...) clauses.
SELECT COUNT(*) as total, COUNT(*) FILTER (WHERE item_type = 'lost') as total_lost, COUNT(*) FILTER (WHERE status = 'Open') as open ... FROM items
delete(int $id): bool
Permanently deletes item. Foreign keys with ON DELETE CASCADE remove its claims and activity logs automatically.
DELETE FROM items WHERE id = :id
logActivity(int $id, string $action, string $details = ''): bool
Inserts a record into the item's audit trail.
INSERT INTO activity_logs (item_id, action, details) VALUES (:id, :action, :details)
getActivityLogs(int $id): array
Retrieves the 20 most recent audit logs for an item.
SELECT * FROM activity_logs WHERE item_id = :id ORDER BY created_at DESC LIMIT 20

Fetches claims joined with item title for the Admin Claims Desk.

updateClaimStatus(int $cid, string $status, string $notes = ''): bool
Transactional decision handler: updates claim to 'Approved' or 'Rejected'. If Approved, marks item as 'Resolved'. If Rejected and no pending claims remain, reverts item to 'Open'.
UPDATE claims SET status = :st, admin_notes = :nt, resolved_at = CURRENT_TIMESTAMP WHERE id = :cid RETURNING item_id

5. AJAX API Endpoints (api/)
api/items.php GET • PUBLIC
GET /api/items.php → JSON { success, count, html }
Parameters: q, type, category, status, sort. Powers real-time debounced catalog search.
api/update-status.php POST • REPORTER OR ADMIN
POST /api/update-status.php → JSON { success, item_id, new_status, message }
Parameters: item_id, status ('Open', 'Claim Requested', 'Resolved'), remarks. Checks canManageItem().
api/claims.php POST • SIGNED IN
POST /api/claims.php → JSON { success, claim_id, message }
Parameters: item_id, claimant_name, claimant_email, claimant_phone, proof_description, proof_image. Blocks item's own reporter from submitting a claim.
api/admin-claim-action.php (alias: api/claim-action.php) POST • REPORTER OR ADMIN
POST /api/admin-claim-action.php → JSON { success, claim_id, item_status, decision }
Parameters: claim_id, decision ('Approved' / 'Rejected'), admin_notes. Approving claim marks item as Resolved.
api/admin-item-delete.php POST • ADMIN ONLY
POST /api/admin-item-delete.php → JSON { success, message }
Parameters: item_id. Permanently deletes item and cascades to claims and activity logs.
api/admin-user-role.php POST • ADMIN ONLY
POST /api/admin-user-role.php → JSON { success, message }
Parameters: user_id, role ('user' / 'admin'). Prevents admin from demoting their own logged-in session.
